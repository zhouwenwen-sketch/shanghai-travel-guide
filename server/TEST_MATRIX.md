# 当前 Node 服务验证矩阵

以下记录只列出已实际执行的隔离 MySQL 验证，不把未编写的 Jest 测试计入通过。

| 模块 | 已验证场景 | 结果 | 后续自动化测试重点 |
| --- | --- | --- | --- |
| 用户 | 注册、登录、JWT 当前用户、字段契约 | 通过 | 过期 token、错误 issuer、并发同名注册 |
| 酒店与 POI | 列表、详情、搜索、POI 分页 | 通过 | 负数与超安全整数 ID、null 字段契约 |
| 收藏与历史 | 收藏、重复收藏、同酒店历史覆盖 | 通过 | 收藏并发唯一键、历史并发上限 |
| 订单 | 创建、金额、重放、同键冲突、取消、过期版本、非法参数 | 通过 | 并发同键、跨用户访问 |
| 行程 | 创建、添加酒店项目、父版本递增 | 通过 | 日期越界、31 天上限、POI 类型、并发编辑、重复删除 |
| 管理员 POI | ADMIN 新增更新下架、USER 403、旧版本 409、非法坐标 400 | 通过 | 重复标签、并发更新、已下架恢复 |

当前自动化单元测试覆盖 JSON 契约、订单时间/幂等键/版本头、行程日期边界、用户注册与登录拒绝路径。真实 MySQL 验证仍单独记录；这份矩阵不是集成测试替代品。
